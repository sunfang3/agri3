# Roadmap

## Phase 1: Prove It Works（MVP）

**Hypothesis:** 我们相信区县管理员愿意把 Excel 工作流迁移到系统，学员
愿意看推送的"专属适配清单"。
**We'll know it's true when:** 标杆试点区县有 >80% 管理员周活 +
>30% 学员 MAU + 至少 1 项政策的"推送→查看→申报"完整路径被走通。

**Goal:** 验证管理员 + 学员的采纳意愿，验证匹配价值的可感知性。

**Deliverables（Features）：**
- MVP 7 大模块（见 mvp-plan.md v1.1）：学员画像 + 政策库 + 课程 +
  规则匹配 + App 内消息 + 区县后台 + 基础埋点
- 1 个标杆试点区县上线运行（单区县深度服务）

**Exit criteria:**
- 试点区县达到：管理员周活 >80% + 学员 MAU >30%
- 至少 1 条政策推送 → 学员查看 → 实际申报的完整闭环被验证
- 学员 NPS 调研 ≥ 30
- 收集至少 20 条结构化用户反馈进入 V1.1 backlog

---

## Phase 2: Make It Repeatable（V1.1）

**Hypothesis:** 我们相信在 MVP 验证后，加入 AI 语音笔记、PDF 自动解析、
动态画像、多通道推送、扫码签到、照片留痕能让学员使用深度显著提升，
让管理员效率显著提升。
**We'll know it's true when:** AI 语音笔记周使用率 >20% 学员，
PDF 自动解析减少 >70% 管理员录入时间，多通道推送打开率 >40%。

**Goal:** 把 MVP 的成功模式从 1 个区县复制到更多区县，同时把人工操作
自动化，恢复 MVP 阶段砍掉的功能（U9/U10/U12）。

**Deliverables：**
- 政策 PDF 自动解析（NLP + 正则 + 人工校对界面）
- AI 语音笔记（ASR + LLM 结构化提炼）
- T-I-P-S 动态阶段判定（规则引擎可配置）
- 多通道推送（SMS + WebPush + 微信公众号模板消息）
- 扫码签到 + GPS 验证（U9 复活）
- Photo 留痕 + 时间地点水印（U10 复活）
- 师资库 + 课程深度标签化
- 学情调查体系（训前需求 + 训中日评 + 训后考试）
- 基础驾驶舱（市级管理员，SQL 查询 + 简单图表）
- 反馈闭环数据回流到匹配引擎（首次模型优化）
- 扩展到 3-5 个区县

**Exit criteria:**
- 3+ 区县上线，>1000 学员注册
- AI 语音笔记周使用率 >20% 学员
- PDF 解析减少 >70% 录入时间
- 多通道推送打开率 >40%
- 完成首次匹配模型权重优化迭代
- 学员 NPS ≥ 40

## Phase 3: Scale It（V1.2 完整版）

**Hypothesis:** 我们相信在数据积累后，匹配引擎可以做到实时 + 个性化，
并能反向输出资源缺口分析给政策制定者。
**We'll know it's true when:** 实时匹配 <1s 响应，资源缺口分析报告
被市农广校采纳用于政策建议。

**Goal:** 精准匹配决策引擎定位坐实，从"工具"升级为"决策支持"。

**Deliverables：**
- 实时匹配引擎（余弦相似度 + 在线计算）
- 物化视图驾驶舱大屏（全市 / 区县 / 产业多维）
- 资源缺口分析 + 预警中心
- 成效归因（匹配贡献度回溯）
- 案例展示墙 + 社群贡献分
- 农技知识库全文检索
- 导师语音答疑
- 推广到济南市全部区县

**Exit criteria:**
- 济南市全覆盖，>5000 学员
- 实时匹配响应 <1s
- 资源缺口分析报告被采纳 ≥ 1 次
- 匹配准确度（学员反馈"准确"比例）>70%
- 学员 NPS ≥ 50

---

## Deferred（Backlog）

| 项目 | 暂缓原因 |
|---|---|
| 多语言支持 | 济南为主，无现实需求 |
| 区块链证书（荣誉防伪） | 优先级低，传统审核已够 |
| VR/AR 现场培训辅助 | 远期探索，技术不成熟 |
| 个性化学习路径 AI 推荐 | V2.0+，需大量行为数据 |
| 跨市协同 | 非本项目职责（市农广校内部） |
