# MVP Plan v1.1（Phase 5 后权威版本）

**版本：** 1.1（替代 v1.0）
**生效日期：** 2026-06-17
**变更摘要：** 应用 Phase 5 SCOPE REDUCTION 削减 + Design Review 设计补强 + 齐鲁农云判断修正  
**底座说明（2026-07-19）：** 产品范围不变；实现仓库为 **agri3**，数据面从 PostgreSQL+pgbus 迁到 **Litestack AIO**（见 `docs/product/tech-stack.md`）。

## Core Value Proposition
让区县管理员把"每月手工 Excel 汇总报名/考勤/反馈"的工作流搬到系统里，
同时让学员第一次看到"专属适配清单"。这两件事一起验证两个核心假设：
(A1) 管理员愿意迁移工作流，(A2) 学员愿意看推送。

**项目定位：** 济南市农广校内部管理平台，与省级齐鲁农云平台无关联。

## MVP Scope

### Must Have（MVP gates on these）
1. **学员注册 + 基础画像采集**（T 象限 + 部分 I 象限）
   - 手机号注册、区县（自动分组）、姓名、主业、规模、年收入、已获荣誉
   - **Excel 历史学员数据批量导入 + dry-run preview**（Design Review D1）
2. **政策资源库 + 人工标签化**（极简）
   - Avo 资源：title / content_text / valid_until / tag_ids[]
   - PDF 上传存文本（V1.1 上自动解析）
   - 标签基础结构：适用对象、产业、规模门槛、收入门槛、截止日期
3. **课程管理 + 报名闭环**（极简）
   - 管理员创建课程，指派 mentor、时间、地点
   - 学员选课 → 管理员审核 → 报名确认
   - **4 状态正式审核流**：pending / enrolled / completed / dropped
4. **匹配引擎（规则版）**
   - 标签交集 / 政策要求标签数 = 匹配度（0-100）
   - score + status enum 两字段（C7 简化，砍 reason_tags[]）
   - T+1 定时任务（Litejob + cron/timer；历史版为 pgbus recurring）
5. **学员 PWA（2 Tab）**
   - **首页**：推荐清单（带 D3 三优先级层级）+ 选课入口 + App 内消息红点
   - **我的**：T-I-P-S 画像简版 + 标签（可修正错误标签）
   - **App 内消息红点替代多通道推送**（C3，砍 SMS/WebPush/公众号）
6. **区县管理员后台（Avo 极简）**
   - 本区学员列表 + 多维筛选（标签、阶段、报名状态）
   - 报名批量 confirm
   - **Avo 默认 CSV 导出**（C6，砍自定义 Excel；V1.1 升级）
   - **区县汇总视图**（差异化卖点，对抗"不如 Excel 方便"风险 K9）
7. **基础埋点**（C9 新加 Must Have）
   - 用户登录、关键操作、页面访问
   - 数据写 `analytics_events` 表（用于验证 A1+A2 实际采纳）

## Go-to-Market Approach
**行政指令型分发（非市场获客）：**
- 第 0 周：市农广校发红头文件，召集 1 个标杆试点区县农广校负责人会议
- 第 1 周：导入历史 Excel 学员数据；管理员熟悉后台
- 第 2 周：录入首批 10 项政策 + 5 门课程；标签库初始化
- 第 3 周：集中组织学员注册 + 首次选课（区县管理员线下推动）
- 第 4 周：第一次现场培训 + **手工记考勤**（U9 已砍）+ 反馈问卷

## What We'll Do Manually (Pre-Scale)
- 政策 PDF 内容提取：管理员手动录入为主（V1.1 上 AI 解析）
- 学员画像数据清洗：管理员人工核对 Excel 迁移结果
- 课程标签化：管理员手动配置匹配规则
- 推送时机决策：管理员手动决定何时让推荐生效
- 成效追踪抽样：电话回访 10-20 名学员
- **考勤记录**：管理员手工记录（学员扫码签到 V1.1 上）
- **照片留痕**：微信群继续做（数字化 V1.1 上）
