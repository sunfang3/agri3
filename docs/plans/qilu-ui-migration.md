# 齐鲁界面原型 → Rails

本次以 `docs/qilu-agri-ui/01–09` 为界面参考，将其布局与功能接入现有 Phlex / Hotwire 应用。原型 HTML 和演示数据保留作设计参考；运行时使用 Rails 路由、数据库和权限。

## 页面对应

| 原型 | Rails 页面 | 数据与操作 |
| --- | --- | --- |
| 01 门户 / 登录 | `/`、`/student/login`、`/admin/login` | 真实平台规模、会话登录、注册入口 |
| 02 学员首页 | `/student/home` | 分级推荐、政策检索、匹配依据、课表、需求提交、消息 |
| 03 全息画像 | `/student/me` | T/I/P/S 四象限、基础资料及标签编辑、需求状态、能力雷达、学习档案、荣誉、答疑 |
| 04 课程 | `/student/courses`、`/student/courses/:id` | 条件筛选、月历、报名状态、容量、签到、照片、音频/文本笔记、问卷 |
| 05 成果 | `/student/achievements` | 评估成长曲线、同阶段均值、荣誉、作品、案例、政策进度、CSV 报告 |
| 06 管理概览 | `/admin` | 区县规模、阶段分布、区县概览、报名月度分布、操作清单、动态 |
| 07 驾驶舱 | `/admin/cockpit` | 转化漏斗、区县匹配热力、供给热度、评估分布与成长曲线、缺口预警、匹配触发 |
| 08 学员审核 | `/admin/students`、`/admin/students/:id` | 搜索和多维筛选、既有两级录取与备案、需求回复、荣誉及作品审核、政策进度登记、能力评估、答疑 |
| 09 资源库 | `/admin/resources` | 政策检索及编辑、原文提取校对、标签分组及维护、课程入口、转化统计 |

辅助页面（课程管理、导入、问卷、知识库、消息等）共用新的导航与设计主题。手机端为单列布局，并提供学员四 Tab 快捷导航；表格在容器内滚动。

## 模型调整

- `StudentNeed`：需求内容、处理状态、管理员回复。
- `Honor`：荣誉名称、日期、审核状态、证明材料。原有 `students.honors` 文本继续展示。
- `PolicyInteraction`：查看时间、收藏、申报/获批进度；与匹配评分分离，重新匹配不会抹去办理历史。
- `CapabilityAssessment`：评估日期及六维真实测评分数，生成雷达、成长历史与同阶段均值。
- `Course.capacity`：可空，不设置时保持既有不限人数行为；满额阻止新报名和确认录取。
- `Policy.document_number` / `issuing_authority`：政策文号及发布单位。
- Active Storage 表：补齐原项目已声明的照片/PDF附件底座，新增荣誉证明、语音笔记和作品附件。

迁移：`bin/rails db:migrate`。无需重新 seed，无新增 gem。生产部署前按项目既有要求备份 SQLite 与附件所在的 `storage/`。

## 业务规则与真实性

- 继续使用起步期 / 成长期 / 壮大期 / 示范期，由现有阶段规则判定；原型的“成熟期 / 转型期”不覆盖业务枚举。
- 保留市直班市级录取、所属区备案；区办班开班区录取、市级只读。
- 学员提交的荣誉与作品默认待审核，不能通过请求参数自行批准；区县管理员只能处理授权范围内的学员。
- 共享标签可浏览；维护需市级或系统管理员。
- 驾驶舱和成果均使用实际记录，缺少评估时显示空状态，不生成演示能力分或虚构提升值。申报进度为行政跟踪登记，不代表自动对接政策办理系统。
- 既有 ASR / LLM / 外部推送适配器保持原状；本次音频上传保存原始材料供后续转写，不用 Fake ASR 冒充转写结果。政策字段提取使用录入原文与现有规则，暂不接入外部 OCR/PDF 服务。
- 签到码改为带期限的签名令牌，管理员在可管理课程详情生成；学员通过签到链接或填写令牌提交经纬度，浏览器可请求定位。
- 实操照片展示上传原图及时间地点说明，不宣称已将水印烧录进图片。

## 验证

`test/integration/workspace_migration_test.rb` 覆盖主页面路由、需求与荣誉审核、政策转化、能力评估、跨区隔离、学习档案检索、附件上传、作品发布、签名签到、容量与标签维护权限。

运行 `bin/rails test`、`bin/rubocop`、`bin/rails zeitwerk:check`。浏览器检查门户及学员/管理端主页面，在桌面与 390px 手机宽度检查渲染、导航和横向溢出。

Litesearch 的中文索引由运行时初始化，`schema_dumper` 排除依赖 tokenizer 的虚表，保证新测试库可从 schema 加载。
